# lhg-mp-menu：一周食谱编排

> 目标：编出一周"吃得下去、做得出来、验算得过"的食谱。
> 核心纪律：**每餐标宏量；蛋白质来源轮换；蔬菜 5 种以上；文件顶部带免责声明。**

> **免责声明**：本 skill 输出的食谱仅供一般性膳食参考，非医疗建议。慢病/备孕人群请遵医嘱。

## 1. 何时使用

- `meta.json`（目标区间）已确认 → 用本 skill 编排一周食谱
- 用户说"食谱吃腻了" → 用第 3.4 节做轮换
- 外卖/食堂党 → 用第 3.5 节替换方案

## 2. 输入输出

**输入**：人群画像卡 + `meta.json`（targets/allergies/group/source）。

**输出**：`menu.md`（一周食谱，`## 周X` + 每餐 `P:xxg C:xxg F:xxg` + kcal 标注，顶部免责声明）。

文件头模板（必带，否则 hook 拦截）：

```markdown
> 免责声明：本食谱仅供一般性膳食参考，非医疗建议。
> 慢病/备孕人群请遵医嘱；如有食物过敏，请自行剔除相关食材。
```

每餐行格式（审计脚本解析用，严格遵守）：

```markdown
- 早餐：燕麦粥 + 水煮蛋 + 牛奶 | P:18g C:45g F:12g | 360kcal
```

## 3. 分步方法论

### 3.1 三餐结构

| 餐 | 热量占比 | 要点 |
|---|---|---|
| 早餐 | 25% | 必须有蛋白质（蛋/奶/豆浆三选一），不许只吃碳水 |
| 午餐 | 35% | 最丰盛的一餐，蛋白质+主食+蔬菜三件套 |
| 晚餐 | 30% | 蛋白质+蔬菜为主，主食减半（减脂）或正常（增肌/备孕） |
| 加餐（可选） | 10% | 水果/酸奶/坚果，只给增肌与备孕人群安排 |

### 3.2 蛋白质来源轮换

全周至少 3 种蛋白质来源，按"禽肉 → 鱼虾 → 蛋 → 豆制品 → 红肉"轮换：

- 周一三五：鸡胸肉/鸡肉系
- 周二四：鱼虾系
- 周末：蛋/豆制品 + 一次红肉（牛肉）

同一蛋白质来源不许连续出现 3 天。

### 3.3 蔬菜 5 种以上

全周至少 5 种蔬菜，深色蔬菜（菠菜/西兰花/胡萝卜）占比一半以上。叶菜与根茎类搭配，避免全周只有"生菜+黄瓜"。

### 3.4 口味轮换（防弃餐）

- 同一菜品不许连续两天出现，一周不许出现 4 次以上
- 烹饪方式轮换：蒸/煮/快炒/凉拌，避免全周水煮
- 每周留 1~2 个"快乐餐位"：在目标区间内允许一顿自己喜欢的（减脂可持续 > 减脂极致）

### 3.5 外食/食堂替换方案

每餐给一个替换选项（外卖党/食堂党用）：

```markdown
- 午餐：鸡胸肉 + 糙米饭 + 西兰花 | P:40g C:60g F:12g | 520kcal
  - 食堂替换：打菜窗口的白切鸡 + 米饭半份 + 炒时蔬（油汤沥掉）
  - 外卖替换：轻食店"鸡胸肉沙拉"，酱料另放、只放一半
```

### 3.6 备孕/慢病专项

- 备孕：剔除生食（刺身/溏心蛋）、酒精、高汞鱼（金枪鱼/剑鱼）；叶酸多从深绿蔬菜来，不许承诺"助孕"
- 高血压：全天盐 <5g 思路——少用咸菜/腊肉/酱菜，调味用醋/柠檬/香料替代部分盐
- 糖尿病：主食粗细搭配、加餐固定时间；**必须**在食谱顶部加粗提醒"血糖管理请遵医嘱，本食谱不替代药物与医生方案"

### 3.7 一周编排实战示例（减脂，5 天展示）

| | 周一 | 周二 | 周三 |
|---|---|---|---|
| 早餐 | 燕麦粥+水煮蛋+牛奶 | 全麦面包+鸡蛋+豆浆 | 玉米+鸡蛋+酸奶 |
| 午餐 | 鸡胸肉+糙米饭+西兰花 | 牛肉+玉米+生菜 | 鸡肉+糙米饭+胡萝卜 |
| 晚餐 | 清蒸三文鱼+红薯+菠菜 | 虾仁+紫薯+芹菜 | 豆腐+红薯+白菜 |

编排思路：蛋白质来源每天换（鸡→牛→虾→鸡→豆），蔬菜每天 3 种不重样，主食粗细搭配。周四周五按同样逻辑轮换，保证全周蛋白质来源≥5 种、蔬菜≥8 种。

### 3.8 做饭小白版（不会做饭专用）

如果画像卡"做饭条件=不会做饭"，食谱降级为"组装式"：

- 早餐：即食燕麦 + 牛奶 + 水煮蛋（便利店可买）
- 午餐：便利店鸡胸肉三明治 + 香蕉
- 晚餐：外卖轻食（备注：酱料另放一半）

组装式食谱的宏量按包装营养成分表标注，并在每餐注明"以包装标注为准"。

## 4. 编排检查清单（出稿前自查）

- [ ] 每天三餐都在吗？宏量标注全吗？
- [ ] 当日加总落在 `meta.json` 目标区间内吗？（心算或跑审计脚本）
- [ ] 过敏原全周零出现吗？（Ctrl+F 搜一遍）
- [ ] 人群禁忌食材零出现吗？（备孕/慢病重点查）
- [ ] 蛋白质来源 ≥3 种？蔬菜 ≥5 种？
- [ ] 有连续重复的菜品吗？
- [ ] 文件顶部有免责声明吗？

## 5. 反模式

### 5.1 常见编排翻车案例

- 案例 A：全周 21 餐用了 4 种做法——用户第 4 天就点外卖了。教训：做法轮换和口味轮换同样重要。
- 案例 B：给不会做饭的用户编了"清蒸三文鱼"——执行率为零。教训：画像卡的"做饭条件"是硬约束，不是参考。
- 案例 C：减脂食谱完全没留快乐餐位——用户第 6 天暴食，前功尽弃。教训：可持续 > 完美。

## 6. 自检与反馈

- ❌ 每餐都写"水煮一切"——三天就弃餐，食谱的可持续性比完美更重要
- ❌ 早餐只有粥/面包——没有蛋白质的早餐，10 点就饿，必然加餐失控
- ❌ 全周 5 天吃同样的"减脂餐"——多样性是营养均衡的前提，也是审计规则
- ❌ 给备孕食谱加"助孕"话术——这是医疗承诺，红线
- ❌ 宏量标注随手写——标注与食材对不上时，审计脚本的交叉验算会标出来，丢的是你的可信度

## 6. 自检与反馈

每次执行完本 skill，做一次轻量自检：

1. 4. 检查清单是否逐项打勾？→ 没打勾不算编完。
2. 是否跑了一遍 `meal_audit.py`？→ 没跑不算数。
3. 备孕/慢病食谱是否经 `safety-reviewer` 视角看过？→ 高风险人群加一道人工。

标准冒烟用例：对 `fixtures/good/menu-good.md` 跑审计脚本，确认零 blocker（见 `smoke_test.py`）。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-meal-plan/issues，正文写清"输入 → 错误输出 → 期望输出"。
