# /lhg-meal-plan:meal-plan —— 一周食谱一键生成

用户输入在 `$ARGUMENTS` 中：`[人群/目标描述] [--days 天数]`，缺省 7 天。

全程加载 `lhg-mp-profile`、`lhg-mp-nutrition`、`lhg-mp-menu` 指导；各环节可分派给 `nutritionist` / `menu-chef` agent。

> **免责声明**：本命令输出仅供一般性膳食参考，非医疗建议。慢病/备孕人群请遵医嘱。

## 流程

### 1. 人群画像（见 lhg-mp-profile）
- 问清四件事：目标人群（减脂/增肌/备孕/慢病四选一）、过敏原与忌口、做饭条件（自己做/外卖/食堂）、预算范围。
- 慢病/备孕人群 → 先出免责声明，再往下走；不许给"治疗性"建议（如"靠食谱降血糖"）。
- 四件事缺任何一件，先问，不许跳过。

### 2. 营养素测算（见 lhg-mp-nutrition）
- 按 lhg-mp-nutrition 第 3 节公式算出每日目标区间（热量/蛋白质/碳水/脂肪），口径注明来源（如《中国居民膳食指南（2022）》）。
- 目标区间写进 `meta.json`（targets/allergies/group/source），后续审计脚本以此为基准。
- 测算过程要展示给用户看，不许只给结果不给算法。

### 3. 一周食谱编排（见 lhg-mp-menu）
- 按 lhg-mp-menu 第 3 节编排：三餐结构、蛋白质来源轮换、蔬菜 5 种以上、口味轮换。
- 每餐标注宏量（`P:xxg C:xxg F:xxg`）与热量，这是审计脚本的输入格式，不许省略。
- 食谱文件顶部必须带免责声明（否则保存时会被 hook 拦截）。

### 4. 采购清单
- 从食谱反推采购清单，按蛋白质/蔬菜/主食/乳制品/水果分类，合并重复项。
- 清单项数量 ≥ 天数×4，缺了说明有食材没覆盖。

### 5. 自检交棒
- 跑 `/lhg-meal-plan:meal-audit`，blocker 清零才能交付。
- 交付物：`menu.md` + `shopping.md` + `meta.json` + 自查报告。

## 硬规则
- 食谱文件没有"非医疗建议"声明 → 不许交付（hook 会拦截）。
- 营养素目标区间没有注明来源 → 不许交付。
- 备孕/慢病食谱出现禁忌食材 → blocker，必须整周剔除。
- 用户说"我有糖尿病，食谱帮我控糖" → 给出一般性建议 + 强烈建议遵医嘱，不许承诺疗效。
