# /lhg-meal-plan:meal-calc —— 营养素测算

用户输入在 `$ARGUMENTS` 中：`[人群 体重 身高 年龄 活动量]`，如 `减脂 70kg 175cm 30岁 久坐`。

全程加载 `lhg-mp-nutrition` 指导；测算可分派给 `nutritionist` agent。

> **免责声明**：测算结果仅供一般性膳食参考，非医疗建议。慢病/备孕人群请遵医嘱。

## 流程

### 1. 确认输入
- 人群四选一：减脂 / 增肌 / 备孕 / 慢病。慢病要追问是哪类慢病（高血压/糖尿病/高血脂），不同慢病禁忌不同。
- 身体数据：体重、身高、年龄、活动量（久坐/轻度/中度/重度）。缺项就问，不许用"平均值"脑补。

### 2. 计算（见 lhg-mp-nutrition 第 3 节）
- 先算基础代谢（Mifflin-St Jeor 公式），再乘活动系数得每日总消耗。
- 按人群目标定热量缺口/盈余：减脂 -300~-500kcal，增肌 +200~300kcal，备孕/慢病维持。
- 三大营养素按体重与目标分配：蛋白质（减脂 1.6~2.2g/kg、增肌 1.6~2.2g/kg、备孕/慢病 1.0~1.2g/kg），脂肪占 20~30%，剩余给碳水。
- 全部计算过程展示给用户，公式与系数写清楚。

### 3. 输出 meta.json
```json
{
  "group": "减脂",
  "targets": {"kcal": [1500, 1800], "protein_g": [90, 120],
              "carbs_g": [150, 200], "fat_g": [40, 60]},
  "allergies": ["花生"],
  "source": "《中国居民膳食指南（2022）》"
}
```
- `source` 必填：目标区间的口径来源，不许空着。
- 输出的区间即审计脚本的判定基准，数字要经用户确认。

## 硬规则
- 身体数据不全 → 不许用平均值脑补，先问。
- source 为空 → 不许输出 meta.json。
- 慢病/备孕 → 测算结果必须附"请遵医嘱"的提醒。
